# IFCSR App — อัปขึ้น GitHub Pages

## ขั้นตอนอัปโหลด (ทำครั้งแรกครั้งเดียว)
1. ไปที่ https://github.com/new สร้าง repository ใหม่ (public) ชื่ออะไรก็ได้ เช่น `ifcsr-app`
2. ในหน้า repo กด "Add file" → "Upload files"
3. ลากไฟล์ทั้งหมดในโฟลเดอร์นี้ขึ้นไป (`index.html`, `manifest.json`, `sw.js`, `icon-192.png`, `icon-512.png`) แล้วกด "Commit changes"
4. ไปที่ Settings → Pages (แถบซ้าย) → ตรง "Branch" เลือก `main` / โฟลเดอร์ `/ (root)` → Save
5. รอ 1-2 นาที จะได้ลิงก์ประมาณ `https://<ชื่อผู้ใช้>.github.io/<ชื่อ-repo>/`
6. เปิดลิงก์นั้นด้วย Chrome บนมือถือ → รอแบนเนอร์ "ติดตั้งแอป" เด้งขึ้น หรือกดเมนู ⋮ → "ติดตั้งแอป"

## อัปเดตไฟล์ครั้งต่อไป (เวลาผมแก้แอปให้ใหม่)
- กลับไปที่หน้า repo บน GitHub → เปิดไฟล์ `index.html` → กดไอคอนดินสอ (Edit) → ลบเนื้อหาเก่าทั้งหมด → วางเนื้อหาไฟล์ใหม่ → Commit
- หรือง่ายกว่า: ลบไฟล์เก่าออกแล้ว Upload files ใหม่ทับ (เลือกไฟล์เดิมชื่อ) ก็ได้
- ไม่ต้องลบแอปที่ติดตั้งในมือถือ เปิดแอปอีกครั้งมันจะโหลดเวอร์ชันใหม่ให้เอง (Service Worker จะอัปเดตแคชให้)

## ข้อมูลสำคัญ
- ข้อมูลที่กรอก/เมนูที่เพิ่มเอง/ราคาที่แก้ เก็บอยู่ใน localStorage ของมือถือแต่ละเครื่อง **ไม่ได้อยู่บน GitHub** และไม่ถูกแชร์กับใคร
- ถ้าจะย้ายข้อมูลไปเครื่องใหม่ ใช้ปุ่ม "Export Backup" / "Import Backup" ในตัวแอป (ดูหัวข้อ 💾 สำรองข้อมูล ในแอป)
